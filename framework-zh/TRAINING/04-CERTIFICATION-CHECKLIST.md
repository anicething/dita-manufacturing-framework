# 认证检查清单

**文档编号：** TRN-004  
**版本：** 1.0  
**最后更新：** 2026-06-07  
**状态：** 已批准  

---

## 概述

本清单由导师或团队负责人用于认证新写作人员具备独立写作能力。所有项目必须完成后方可授予认证。

---

## 培训完成

- [ ] 完成全部 4 个培训练习
- [ ] 练习经导师审核批准
- [ ] 出勤率达到 90% 以上
- [ ] 笔试通过（80% 以上）

---

## 工具熟练度

- [ ] 能在 oXygen 中创建新的 DITA 主题
- [ ] 能在 oXygen 中验证 XML
- [ ] 能使用 Git 进行克隆、分支、提交和推送
- [ ] 能创建 Pull Request 供审核
- [ ] 能解决简单的合并冲突
- [ ] 能发布 HTML5 和 PDF 输出

---

## 写作标准

- [ ] 理解概念/任务/参考三种主题类型的区别
- [ ] 操作步骤遵循 20 字原则
- [ ] 一致使用主动语态
- [ ] 正确使用警告/注意/提示的约定
- [ ] 每个主题包含完整元数据
- [ ] 使用术语表中的批准术语

---

## 质量合规

- [ ] 最近 3 个主题无拼写或语法错误
- [ ] 所有交叉引用正确解析
- [ ] 图片包含替代文本
- [ ] 主题通过 XML 验证（无警告）
- [ ] 风格指南合规性经导师确认

---

## 治理与流程

- [ ] 理解 10 步审批流程
- [ ] 能判断何时需要合规审查
- [ ] 知道如何升级被阻塞的评审
- [ ] 已阅读并签署治理政策确认书
- [ ] 理解 conref 稳定性规则（绝不删除 conref 目标）
