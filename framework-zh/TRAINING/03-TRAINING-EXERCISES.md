## 练习 1：创建概念主题

**目标：** 撰写描述产品功能的概念主题。

**说明：**
1. 从 `templates/concept.dita` 打开概念模板
2. 将占位内容替换为真实产品信息
3. 包含至少一个带项目列表的 `<section>`
4. 添加完整元数据（作者、产品、受众）
5. 验证 XML

**检查清单：**
- [ ] 标题为名词短语（如"主轴组件概述"）
- [ ] 首段定义主题
- [ ] 章节逻辑有序
- [ ] 不包含操作步骤（属于任务主题）
- [ ] 元数据完整
- [ ] XML 验证通过

---

## 练习 2：创建任务主题

**目标：** 编写一个 5 步的操作任务。

**说明：**
1. 从 `templates/task.dita` 打开任务模板
2. 编写包含前置条件、5 个步骤和预期结果的任务
3. 每步为一个操作（一句话，不超过 20 字）
4. 在适当时添加警告 `<note type="warning">`
5. 验证并检查

**检查清单：**
- [ ] 标题以动词开头（如"安装驱动皮带"）
- [ ] 步骤前列出前置条件
- [ ] 每步是一个操作指令
- [ ] 预期结果描述成功的标准
- [ ] 警告放在相关步骤之前
- [ ] XML 验证通过

---

## 练习 3：创建参考主题

**目标：** 为技术规格创建参考表格。

**说明：**
1. 从 `templates/reference.dita` 打开参考模板
2. 创建包含技术规格的 `<table>`
3. 至少包含 5 行数据
4. 添加 `<strow>` 表头行
5. 验证并检查

**检查清单：**
- [ ] 标题为名词短语
- [ ] 表格有清晰的列标题
- [ ] 包含计量单位
- [ ] 数据准确（与产品规格核对）
- [ ] 无叙述性文字（参考 = 查阅，非阅读）
- [ ] XML 验证通过

---

## 练习 4：构建 DITA Map

**目标：** 将 3 个主题组织成可导航的 DITA Map。

**说明：**
1. 创建新的 `.ditamap` 文件
2. 为主题添加 `<topicref>` 条目
3. 为每个主题设置 `<navtitle>`
4. 创建层级结构（一个主主题，两个子主题）
5. 使用 DITA-OT 生成 HTML5 输出
6. 验证输出渲染正确

**检查清单：**
- [ ] Map 有标题
- [ ] 所有 topicref 指向现有文件
- [ ] 导航层级逻辑清晰
- [ ] HTML5 输出无错误生成
- [ ] 发布内容显示正确
