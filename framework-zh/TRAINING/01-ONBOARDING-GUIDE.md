# 入职培训指南 — 四周计划

**文档编号：** TRN-001  
**版本：** 1.0  
**最后更新：** 2026-06-06  
**状态：** 已批准  

---

## 概述

本四周培训计划旨在培养新作者掌握 DITA 基础知识、风格指南、工具和流程。

**总课时：** 40 小时  
**时间投入：** 每周 8-10 小时  
**培训形式：** 课堂教学、动手实操和自学相结合  

---

## 第 1 周：DITA 基础知识（10 小时）

### 周一：介绍入门（2 小时）
- 什么是 DITA 以及我们为什么使用它
- 三种主题类型：概念、任务、参考
- DITA 与传统文档的区别
- 制造业的收益：重用、本地化、合规

**活动：** 查看您所负责产品的 DITA 主题示例

### 周二至周三：主题结构（4 小时）
- 概念主题的结构和示例
- 任务主题的结构和示例
- 参考主题的结构和示例
- 何时使用每种类型

**活动：** 在现有文档中识别主题类型

### 周四：DITA 元素（2 小时）
- 常用 DITA 元素：`<topic>`、`<section>`、`<p>`、`<ul>`、`<table>`
- 元数据：是什么以及为什么重要
- 验证：如何检查您的主题

**活动：** 创建第一个简单主题

### 周五：映射与组织（2 小时）
- DITA 映射：主题如何组织
- 导航结构
- 交叉引用和链接
- 重用概念

**活动：** 创建一个包含 3 个主题的简单映射

---

## 第 2 周：风格指南与标准（10 小时）

### 周一：写作标准（2 小时）
- 制造业的语调和语气
- 清晰、简洁、一致、合规
- 目标受众：管理员、用户、开发者
- 全球受众注意事项

**活动：** 编辑示例主题以符合风格标准

### 周二：格式与术语（2 小时）
- 标题、列表、表格、强调
- 您所负责产品的批准术语
- 警告、注意、提示
- 图片和屏幕截图

**活动：** 正确格式化示例内容

### 周三：操作步骤与代码（2 小时）
- 如何正确编写任务主题
- 逐步操作的结构和示例
- 代码块和行内代码
- 便于本地化的写作方式

**活动：** 编写一个简单的 3 步操作流程

### 周四：质量检查清单（2 小时）
- 质量检查清单回顾
- 元数据要求
- 常见错误及避免方法
- 无障碍访问和合规

**活动：** 自审一个示例主题

### 周五：测验与回顾（2 小时）
- 书面评估（20 道题）
- 回顾关键概念
- 与高级作者的问答交流
- 为工具培训做准备

---

## 第 3 周：工具培训（10 小时）

### 周一：oXygen XML Editor（3 小时）
- 安装和设置
- 创建新主题
- 验证 XML
- 发布为 HTML/PDF
- 版本控制集成

**活动：** 在 oXygen 中创建主题并发布

### 周二：版本控制与 Git（3 小时）
- Git 基础和工作流
- 创建分支
- 提交更改
- Pull Request 和代码审查
- 分支保护规则

**活动：** 提交第一个 PR 供审查

### 周三：CI/CD 流水线（2 小时）
- 自动发布的工作原理
- CI/CD 流水线概述
- 构建日志和故障排除
- 多渠道发布

**活动：** 观察您的第一次自动发布

### 周四：本地化与搜索（2 小时）
- 内容如何被翻译
- 翻译记忆库
- 搜索索引
- 多语言门户网站

**活动：** 从 TMS 中查看已翻译的内容

---

## 第 4 周：动手实践项目（10 小时）

### 周一：项目分配（2 小时）
- 分配真实的产品文档任务
- 评审需求和验收标准
- 与主题专家和产品经理讨论
- 规划您的工作

### 周二至周三：内容创建（4 小时）
- 为您的产品创建 2-3 个实际主题
- 遵循所有标准和指南
- 包含正确的元数据
- 添加交叉引用

### 周四：提交与审核（2 小时）
- 提交包含主题的 PR
- 参与代码审查反馈
- 进行要求的修改
- 合并到生产环境

### 周五：认证（2 小时）
- 评估完成
- 反馈讨论
- 认证获批
- 准备好独立工作了！

---

## 评估标准

**书面测试（25 分）**
- DITA 基础知识：10 分
- 风格指南知识：10 分
- 流程理解：5 分
- **通过线：** 20/25（80% 以上）

**实践项目（25 分）**
- 主题质量：10 分
- 元数据完整性：5 分
- 风格指南合规：5 分
- 可重用性/结构：5 分
- **通过线：** 20/25（80% 以上）

**出勤与参与（10 分）**
- 出勤率：5 分（必须达到 90% 以上）
- 参与度：5 分（积极提问/讨论）
- **通过线：** 8/10（80% 以上）

---

## 认证

**作者满足以下条件即可获得认证：**
- [ ] 完成所有培训课程（38 小时以上）
- [ ] 书面测试通过（80% 以上）
- [ ] 实践项目成功完成
- [ ] 前 3 个主题已审核并批准
- [ ] 签署理解治理政策的声明
- [ ] 通过工具熟练度检查

**获得认证后：**
- ✅ 获准独立创作主题
- ✅ 加入审批工作流
- ✅ 获得共享内容仓库的访问权限
- ✅ 受邀参加每月最佳实践会议

---

## 培训后支持

**第 5 周及之后：**
- 与高级作者导师配对（4 周）
- 每周检查会议
- 前 10 个主题的代码审查反馈
- 可获取培训材料和模板
- 每月继续教育（1 小时）

**年度重新认证：**
- 4 小时复习培训
- 获取流程变更的最新信息
- 最佳实践回顾
- 与领导层的问答交流
