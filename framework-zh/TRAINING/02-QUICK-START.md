## 快速定位

### 文件位置概览

| 资源 | 位置 | 用途 |
|------|------|------|
| 风格指南 | `STYLE-GUIDE/01-STYLE-GUIDE.md` | 写作规则与标准 |
| 主题模板 | `templates/` | 即用型 DITA XML 模板 |
| 审批流程 | `WORKFLOWS/01-APPROVAL-WORKFLOW.md` | 内容发布流程 |
| 产品主题 | `src/<产品>/` | 写作工作目录 |

### 第一个任务

1. 选择一个分配给你的简单概念主题
2. 从 `templates/` 打开对应模板
3. 阅读 2 篇类似主题作为参考
4. 按照风格指南撰写初稿
5. 运行质量检查清单（参见培训材料）
6. 通过 Pull Request 提交同行评审

### 需要帮助？

- **即时问题：** 询问分配给你的导师
- **工具问题：** 联系 IT 部门（参见工具设置指南）
- **流程问题：** 询问团队负责人
- **风格问题：** 查阅风格指南
