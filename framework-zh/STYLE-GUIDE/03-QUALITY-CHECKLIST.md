## 写作质量

- [ ] 操作步骤每句不超过 20 字，概念不超过 25 字
- [ ] 全文使用主动语态
- [ ] 无模糊词语（简单、只需、基本上、显然）
- [ ] 每句一个从句（操作步骤中不使用分号）
- [ ] 术语一致（同一事物不使用不同说法）
- [ ] 无将来时——使用现在时
- [ ] 无方向性引用（"如上"、"如下"）——使用交叉引用

## 操作任务

- [ ] 标题以动词开头

- [ ] 每个步骤为一个操作
- [ ] 步骤不超过 20 字
- [ ] 最后步骤后说明预期结果
- [ ] 警告放在相关步骤之前，而非之后
- [ ] 无隐性假设
