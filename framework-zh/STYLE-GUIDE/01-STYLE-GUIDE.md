## 1. 写作原则

### 1.1 核心价值观

**清晰（CLARITY）** — 面向全球受众撰写
- 使用简单、直接的语言
- 定义技术术语
- 避免使用习语和文化引用
- 保持句子在 20 个词以内

**简洁（CONCISENESS）** — 尊重读者的时间
- 删除不必要的词语
- 每句只表达一个观点
- 去除冗余内容
- 尽可能减少专业术语

**一致（CONSISTENCY）** — 统一的语调和术语
- 对相同概念使用相同术语
- 保持并列结构
- 遵循品牌语调指南
- 使用经批准的术语表术语

**合规（COMPLIANCE）** — 满足 ISO 和法律要求
- 包含必要的警告
- 引用安全标准
- 在需要时包含免责声明
- 跟踪文档历史记录

## 2. 语法与语言

### 2.1 语调

**专业但平易近人**
- 不建议："确保实施最佳配置参数"
- 建议使用："根据您的环境配置设置"

**优先使用主动语态**
- 不建议："文件应由用户保存"
- 建议使用："保存文件"

**推荐使用第二人称（您）**
- 不建议："用户应重新启动应用程序"
- 建议使用："您可以重新启动应用程序"

### 2.2 时态

- **现在时**用于操作步骤和当前状态
  - "点击保存"
  - "系统显示确认消息"
- **将来时**用于预期结果
  - "您将看到结果"
  - "文件将被上传"
- **避免在操作步骤中使用过去时**
  - 不建议："点击了保存，文件已保存"

### 2.3 数字

**0-9 使用文字拼写，10 及以上使用阿拉伯数字**
- "您需要五分钟"
- "系统支持 25 种语言"

**例外情况（始终使用阿拉伯数字）：**
- 测量值："2 GB RAM"
- 百分比："50%"
- 版本："Version 2.1"
- 代码："Error 404"

## 3. 格式与结构

### 3.1 标题

**层级结构（主题中最多 3 级）：**
```
第 1 级（H1）：<title> — 主题标题
第 2 级（H2）：<section title> — 主要章节
第 3 级（H3）：<section title> — 子章节
```

**标题风格：**
- 使用句子式大小写（非标题式大小写）
- "系统入门指南"
- "配置安全设置"
- 使标题具有描述性和针对性

### 3.2 列表

**无序列表：** 用于无顺序要求的项目
```
支持的文件格式：
- PDF
- Word (.docx)
- Excel (.xlsx)
- CSV
```

**有序列表：** 用于步骤、操作流程、优先级
```
安装软件：
1. 下载安装程序
2. 运行安装向导
3. 接受许可协议
4. 选择安装目录
5. 点击完成
```

**要求保持并列结构：**
- 所有项目使用相同的语法形式
- 不建议："1. 安装软件，2. 配置，3. 运行应用程序"
- 建议使用："1. 安装软件，2. 配置设置，3. 运行应用程序"

### 3.3 表格

**用于对比、规格说明、参考数据**

```
产品型号    | 处理器   | 内存 | 存储  | 价格
─────────────────────────────────────────────
基础版     | 双核     | 4GB  | 256GB | $500
专业版     | 四核     | 8GB  | 512GB | $800
企业版     | 八核     | 16GB | 1TB   | $1200
```

**表格指南：**
- 第一行 = 表头（加粗）
- 列对齐保持一致
- 行内容保持简洁
- 用于比较 3 个以上项目时使用

### 3.4 强调

**加粗** — 界面元素、重要术语
```
点击**保存**按钮。
**API Key** 为必填项。
```

**斜体** — 变量、文件名、强调
```
将 *username* 替换为您的登录名
编辑 *config.xml* 文件
```

**代码/等宽字体** — 命令、代码、文件路径
```
输入命令：`npm install`
编辑 */etc/config/settings.conf*
```

**避免使用全大写**（缩写词除外）
- 不建议："请勿删除此文件"
- 建议使用："请勿删除此文件"

## 5. 警告、注意事项与提示

### 5.1 警告 ⚠️ WARNING（对用户/数据有危险）

```
⚠️ 警告：此操作不可撤销。所有数据将被永久删除。
请确保在继续之前已进行备份。
```

**使用场景：**
- 破坏性操作（删除、格式化、覆盖）
- 安全风险
- 数据丢失风险
- 安全隐患

### 5.2 注意 ⚠️ CAUTION（可能导致不良结果）

```
⚠️ 注意：更改这些设置可能会影响系统性能。
请先在非生产环境中进行测试。
```

**使用场景：**
- 性能影响
- 兼容性问题
- 配置冲突
- 不可逆的更改

### 5.3 提示 📝 NOTE（有用信息）

```
📝 提示：您必须具有管理员权限才能执行此任务。
```

**使用场景：**
- 前提条件信息
- 实用技巧
- 相关信息
- 平台特定说明

## 6. 编写操作步骤（任务）

### 6.1 任务结构

```
任务标题（动作动词 + 对象）
│
├─ 简短描述（1-2 句话）
├─ 目的（何时需要执行此操作？）
├─ 前提条件（如有）
├─ 步骤（带编号，简洁明了）
├─ 预期结果
├─ 提示/后续步骤（可选）
└─ 相关任务（链接）
```

### 6.2 步骤编写指南

**每个步骤以动作动词开头：**
- 打开、点击、选择、输入、选择、右键、双击、复制、粘贴

**描述要具体明确：**
- 不建议："点击按钮"
- 建议使用："点击**保存**按钮"

**通常每步只包含一个动作：**
- 不建议："打开文件并选择选项"
- 建议使用：
  1. 打开文件
  2. 选择选项

**包含每个步骤的预期结果（如不明显）：**
```
1. 点击**确定**
   设置已保存，对话框关闭。
```

## 8. 图片与视觉元素

### 8.1 图片指南

**文件格式：**
- PNG（首选）用于屏幕截图
- JPG 用于照片
- SVG 用于图表

**大小优化：**
- 每张图片最大 500 KB
- 屏幕截图：最低 800x600
- 使用压缩工具

**替代文本（必填）：**
```
<image href="../images/login_screen.png" 
       alt="登录界面，包含用户名和密码输入框"/>
```

## 9. 本地化注意事项

### 9.1 便于翻译的写作

**避免以下内容：**
- 习语："piece of cake"（小菜一碟）、"break a leg"（祝好运）
- 双关语和文字游戏
- 未经解释的缩写
- 特定文化的引用
- 无法翻译的幽默

**优先使用：**
- 字面化语言
- 允许使用短句片段："点击保存。文件已保存。"
- 主动语态
- 短段落
- 简单的用词选择

### 9.2 便于翻译的结构

**避免长段落**
- 每段最多 3-4 句话
- 每段一个观点
- 短句子（< 20 个词）

**使用一致的术语**
- 维护术语表
- 同一术语始终表示同一概念
- 翻译记忆库重用
