## 通用术语

| 英语术语 | 中文用法 | 避免使用 |
|---------|---------|---------|
| **activate** | 激活 | "打开"、"开启"（针对功能） |
| **approximate** | 大约 | "大概"、"左右"（不精确时） |
| **calibrate** | 校准 | "调整"（用于校准场景） |
| **configure** | 配置 | "设置"（作为动词） |
| **default** | 默认值/预设 | "缺省"（大陆简体中文不用） |
| **deactivate** | 停用 | "关闭"（针对功能） |
| **display** | 显示 | "弹出"、"跳出" |
| **ensure** | 确保 | "保证"（不太精确） |
| **follow** | 按照 | "做"、"执行"（用于步骤） |
| **install** | 安装 | "部署"、"装载"（不精确时） |
| **locate** | 找到 | "寻找"、"查找" |
| **monitor** | 监控 | "监视"（有负面含义） |
| **navigate** | 导航/进入 | "去到"、"点进" |
| **perform** | 执行 | "做"、"运行" |
| **prevent** | 防止 | "避免"（系统动作时） |
| **procedure** | 步骤/流程 | "过程"、"工序"（互换使用） |
| **recommend** | 建议 | "推荐"（正式文档中） |
| **remove** | 拆除/移除 | "删除"（用于实物） |
| **replace** | 更换 | "交换"、"替换" |
| **reset** | 重置 | "清除"、"恢复" |
| **select** | 选择 | "选取"、"挑选"（界面操作） |
| **specify** | 指定 | "输入"、"设置" |
| **verify** | 验证 | "检查"、"确认" |

## 禁止使用的表达

| 避免 | 改用 | 原因 |
|------|------|------|
| "简单"、"容易" | — | 主观判断，并非所有用户都认为简单 |
| "只需"、"只要" | — | 暗示用户不应遇到困难 |
| "显然" | — | 居高临下 |
| "当然" | — | 轻蔑 |
| "基本上" | — | 模糊填充词 |
| "如上所述" | "参见 [xref]" | 精确定位 |
| "点击这里" | "点击**保存**" | 无障碍访问要求 |
| "请" | — | 指令中不必使用 |

## 步骤中的动词形式

| 正确写法 | 错误写法 |
|---------|---------|
| "选择**启动**。" | "您应该选择**启动**。" |
| "配置进给速度。" | "您可以配置进给速度。" |
| "请勿打开面板。" | "您不得打开面板。" |
| "确保主轴已停止。" | "确保主轴已被停止。" |
