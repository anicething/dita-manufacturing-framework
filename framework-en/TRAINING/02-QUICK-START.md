## Quick Orientation

### Where Things Are

| Resource | Location | Purpose |
|----------|----------|---------|
| Style Guide | `STYLE-GUIDE/01-STYLE-GUIDE.md` | Writing rules and standards |
| Topic Templates | `templates/` | Ready-to-use DITA XML templates |
| Approval Workflow | `WORKFLOWS/01-APPROVAL-WORKFLOW.md` | How content gets published |
| Your Product Topics | `src/<product>/` | Where you will write |

### Your First Task

1. Pick a simple concept topic assigned to you
2. Open the corresponding template from `templates/`
3. Read 2 similar existing topics for reference
4. Write a first draft following the style guide
5. Run the quality checklist (see training materials)
6. Submit for peer review via pull request

### Need Help?

- **Immediate questions:** Ask your assigned mentor
- **Tool issues:** Contact IT (see Tool Setup Guide)
- **Process questions:** Ask your team lead
- **Style questions:** Refer to the Style Guide
