---

## Overview

This checklist is used by the mentor or team lead to certify a new writer for independent authoring. All items must be completed before granting certification.

---

## Training Completion

- [ ] Completed all 4 training exercises
- [ ] Exercises reviewed and approved by mentor
- [ ] Attended 90%+ of training sessions
- [ ] Passed written assessment (80%+)

---

## Tool Proficiency

- [ ] Can create a new DITA topic in oXygen
- [ ] Can validate XML in oXygen
- [ ] Can clone, branch, commit, and push with Git
- [ ] Can create a pull request for review
- [ ] Can resolve simple merge conflicts
- [ ] Can publish HTML5 and PDF output

---

## Writing Standards

- [ ] Demonstrates understanding of concept/task/reference distinction
- [ ] Follows the 20-word rule for step instructions
- [ ] Uses active voice consistently
- [ ] Applies correct warning/caution/note conventions
- [ ] Includes complete metadata on every topic
- [ ] Follows approved terminology from the glossary

---

## Quality Compliance

- [ ] No spelling or grammar errors in last 3 topics
- [ ] All cross-references resolve correctly
- [ ] Images include alt text
- [ ] Topics pass XML validation without warnings
- [ ] Style guide compliance verified by mentor

---

## Governance & Process

- [ ] Understands the 10-step approval workflow
- [ ] Can identify when compliance review is needed
- [ ] Knows how to escalate blocked reviews
- [ ] Has read and signed governance policy acknowledgment
- [ ] Understands conref stability rules (never delete a conref target)

---

**Upon certification:**
- Writer is approved to author independently
- Writer is added to review workflows
- Writer receives access to shared content libraries
- Writer is invited to monthly best-practices meetings
