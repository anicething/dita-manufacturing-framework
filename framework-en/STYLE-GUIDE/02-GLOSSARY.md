## General Terms

| Term | Usage | Avoid |
|------|-------|-------|
| **activate** | Enable a feature or function | "turn on", "switch on" |
| **affect** | To have an influence on | "impact" (as verb) |
| **allows** | Describes system capability | "lets you", "enables you to" |
| **approximately** | About, roughly | "approx.", "ca." |
| **assemble** | Put together components | "build", "construct" |
| **calibrate** | Adjust to standard | "set up" (for calibration) |
| **configure** | Set up for operation | "setup" (as verb) |
| **deactivate** | Disable a feature | "turn off", "shut down" |
| **default** | Preset value or behavior | "by default", "default setting" |
| **diagnose** | Identify cause of problem | "troubleshoot" (as verb) |
| **display** | What appears on screen | "show", "pop up" |
| **ensure** | Make certain | "make sure", "guarantee" |
| **follow** | Perform as instructed | "do", "execute" (for steps) |
| **install** | Set up hardware/software | "load", "deploy" (when not precise) |
| **locate** | Find the position of | "find", "look for" |
| **monitor** | Observe over time | "watch", "track" |
| **navigate** | Move through a menu/screen | "go to", "click through" |
| **perform** | Carry out an action | "do", "execute", "run" |
| **prevent** | Stop from happening | "avoid" (when system action) |
| **procedure** | Series of steps | "process", "workflow" (interchangeable) |
| **recommend** | Suggest best practice | "suggest", "advise" |
| **remove** | Take away or detach | "delete" (for physical objects) |
| **replace** | Put new item in place of old | "swap", "exchange" |
| **reset** | Return to original state | "clear", "restore" |
| **select** | Choose from options | "pick", "choose" (in UI) |
| **specify** | State precisely | "enter", "set" |
| **verify** | Check accuracy | "check", "confirm", "validate" |

## Manufacturing-Specific Terms

| Term | Definition |
|------|-----------|
| **CNC** | Computer Numerical Control — automated machine tool |
| **HMI** | Human-Machine Interface — operator control panel |
| **PLC** | Programmable Logic Controller — industrial computer |
| **spindle** | Rotating shaft that holds the cutting tool |
| **chuck** | Clamping device that holds the workpiece |
| **coolant** | Fluid used to cool the cutting area |
| **feed rate** | Speed at which the cutting tool moves through material |
| **tolerance** | Allowable deviation from specified dimension |
| **axis** | Direction of movement (X, Y, Z, etc.) |
| **servo motor** | Motor with position feedback for precise control |
| **encoder** | Sensor that converts position to electronic signal |
| **ball screw** | Precision lead screw for linear motion |
| **way cover** | Protective cover for machine guide rails |
| **chip** | Waste material removed by cutting |
| **workpiece** | The material being machined |

## Do Not Use

| Avoid | Use Instead | Reason |
|-------|-------------|--------|
| "easy", "simple" | — | Subjective; not all users find it so |
| "just", "simply" | — | Implies user is wrong if they struggle |
| "obviously" | — | Condescending |
| "of course" | — | Dismissive |
| "basically" | — | Vague filler |
| "like" (as filler) | — | Informal |
| "you'll notice" | — | Presumptuous |
| "as mentioned above" | "see [xref]" | Precise reference |
| "click here" | "click **Save**" | Screen-reader accessible |
| "please" | — | Unnecessary in instructions |

## Verb Forms in Procedures

| Use | Avoid |
|-----|-------|
| "Select **Start**." | "You should select **Start**." |
| "Configure the feed rate." | "You can configure the feed rate." |
| "Do not open the panel." | "You must not open the panel." |
| "Ensure the spindle is stopped." | "Make sure that the spindle has been stopped." |
