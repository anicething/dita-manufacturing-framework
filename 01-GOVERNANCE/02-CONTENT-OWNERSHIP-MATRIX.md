## Roles & Responsibilities

### DITA Architect
- Maintain style guide and metadata standards
- Review all shared content before publication
- Manage glossary and terminology
- Approve specializations and structure changes
- Conduct quarterly architecture audits

### Product Manager (Product A/B/C)
- Approve product-specific documentation for release
- Define product documentation priorities
- Review release notes and marketing alignment
- Provide feedback on customer satisfaction

### Senior Writer (Product A/B/C)
- Lead documentation team for their product
- Review quality and consistency
- Mentor product writers
- Coordinate with other products on shared topics
- Report metrics to DGC

### Product Writer (Product A/B/C)
- Create product-specific topics
- Follow style guide and templates
- Participate in content reuse
- Submit topics for review

### QA Writer (Product A/B/C)
- Create test-scenario documentation
- Update troubleshooting guides
- Report bugs/issues to Senior Writer
- Ensure technical accuracy

### Support Lead
- Create FAQ documentation
- Update knowledge base
- Report common customer issues
- Suggest content improvements

### Developer Relations
- Create API documentation
- Maintain code examples
- Ensure technical accuracy
- Update API reference per release
